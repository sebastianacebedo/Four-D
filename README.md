# FOUR-D Furniture App

A mobile-first, single-page web application showcasing **FOUR-D Furniture**, a premium Filipino furniture brand based in Metro Manila.  
This project presents a high-fidelity UI/UX concept for browsing collections, viewing product details, and submitting customer inquiries.

The application is built using **vanilla HTML, CSS, and JavaScript**, with a strong emphasis on visual design, smooth transitions, and mobile app–like interactions.

---

## ✨ Key Features

- 📱 Mobile-first UI styled to resemble a native mobile application
- 🛋️ Product catalog & collections with category filtering
- 🔍 Detailed product views including materials, specs, and pricing ranges
- 🧭 Animated screen navigation (Home, Collections, Product Detail, Inquiry, About, Showroom)
- 📝 Inquiry form with validation and success feedback
- 🎨 Premium visual design using custom CSS variables, gradients, and animations
- 🇵🇭 Brand storytelling centered on Filipino craftsmanship

---

## 🛠️ Tech Stack

- **HTML5** – Semantic markup and screen structure  
- **CSS3** – Custom properties, animations, and responsive layout  
- **JavaScript (Vanilla)** – State management, navigation, rendering logic  
- **Google Fonts** – Playfair Display, DM Sans, DM Serif Display  

No frameworks, build tools, or external dependencies are required.

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Edge, Firefox, Safari)
- (Optional) A local static server

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sebastianacebedo/Four-D.git
   ```

2. Navigate into the project directory:
   ```bash
   cd Four-D
   ```

3. Open the app:
   - Option A: Double-click `index.html`
   - Option B (recommended): Run a local server
     ```bash
     npx serve
     ```

## 🧭 Application Screens

- **Splash Screen** – Brand introduction and loading animation  
- **Home** – Hero section, statistics, categories, featured products  
- **Collections** – Filterable product grid by category  
- **Product Detail** – Materials, specs, description, pricing range  
- **Inquiry** – Customer form with confirmation overlay  
- **About** – Brand story, timeline, and values  
- **Showroom** – Location, hours, and contact details  

Navigation is handled entirely client-side with animated transitions.

---

## 🧠 Design Philosophy

FOUR-D is designed to feel **luxurious, calm, and premium**, reflecting:
- Filipino craftsmanship
- Sustainability and longevity
- Boutique furniture branding

The UI avoids clutter, prioritizes readability, and mimics the behavior of a native mobile application.
